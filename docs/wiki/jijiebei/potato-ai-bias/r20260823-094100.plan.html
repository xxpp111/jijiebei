# 土豆 AI 加权彩蛋 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `accounts` 增加管理员维护的土豆标记，并在账号标记或选手名包含“土豆”时，以实际约 76.32% 的单场概率抽到“旧世机械团”，在 Select/Battle/OBS 展示“土豆的老朋友”。

**Architecture:** 会话入口负责从认证快照与单/双打选手名计算 `potatoBiasActive`，再把冻结布尔值传给纯随机模块；`aiEnemySelector` 只接收 `rng` 与 `potatoBiasActive`，生成带稳定 AI ID 和彩蛋标记的三场结果。PocketBase amendment migration 只负责新增字段及禁止普通账号持久化自开，不承担浏览器防伪。

**Tech Stack:** React 18、TypeScript、Vite/Vitest、PocketBase 0.39 Go migrations、Node/Vite SSR E2E、Playwright、Harness-Pro。

## Global Constraints

- 已批准触发条件：`accounts.potato_ai_bias === true`，或单打 `SelectState.playerName` / 双打 `_players[0..1]` 中任一名称包含连续中文“土豆”。
- 已批准概率：每场 75% 直接命中；剩余 25% 从完整 19 项池抽取；最终为 `29/38 ≈ 76.32%`，三场可全部相同。
- 所有随机敌方模式、练习和正式比赛都生效。
- 凡触发态下最终抽到 `T_MechClassic`，均显示“土豆的老朋友”，不区分直达或普通池来源。
- 不修改 codec schema v1，不处理 BP 无限重抽、贴码敌方还原或服务端抽签。
- 不修改既有 migration；新增 amendment migration。
- 禁止访问或运行使用 `backend/pb_data/**` 的命令；所有 PB 测试必须显式临时 `--dir`。
- 当前工作树已有 Round S 未提交改动：`1782000008`、`1782000009`、安全 E2E、`backend/verify-all.sh`、`docs/testing.md`、`web/e2e/practice-post.mjs`；不得覆盖、回滚或混淆其归属。
- `projectplan.md` 与 `test-x/**` 完全 no-touch。
- 实现 Spoke 不 commit、不 push、不部署；提交由 parent Hub 单独拍板。
- 使用独立 Harness runtime，例如 `.harness-pro-potato-ai-bias`，planned phases ≥ 4；每条 CLI 显式 `--runtime-dir` 和 review `--model-config`。

```go
const accountsUpdateRuleImmutableRoleAndPotato = "(@request.auth.id = id && @request.body.role:changed = false && @request.body.potato_ai_bias:changed = false) || @request.auth.role = 'admin'"

func init() {
  m.Register(
    func(app core.App) error {
      col, err := app.FindCollectionByNameOrId("accounts")
      if err != nil { return nil }
      if col.Fields.GetByName("potato_ai_bias") == nil {
        col.Fields.Add(&core.BoolField{
          Name: "potato_ai_bias",
          System: false,
          Required: false,
        })
      }
      col.UpdateRule = types.Pointer(accountsUpdateRuleImmutableRoleAndPotato)
      return app.Save(col)
    },
    func(app core.App) error {
      col, err := app.FindCollectionByNameOrId("accounts")
      if err != nil { return nil }
      col.Fields.RemoveByName("potato_ai_bias")
      col.UpdateRule = types.Pointer(accountsUpdateRuleImmutableRole)
      return app.Save(col)
    },
  )
}
```

- [ ] **Step 2: 实现最小随机逻辑**

```ts
const POTATO_AI_ID = 'T_MechClassic';
const POTATO_DIRECT_RATE = 0.75;
const potatoAi = AI_ENEMY_POOL.find((ai) => ai.id === POTATO_AI_ID);
if (!potatoAi) throw new Error('[aiEnemySelector] missing T_MechClassic');

function toRoll(ai: AIEnemy, potatoBiasActive: boolean): EnemyRoll {
  return {
    id: ai.id,
    race: ai.race,
    nameZh: ai.nameZh,
    potatoFriend: potatoBiasActive && ai.id === POTATO_AI_ID || undefined,
  };
}

function rollOne(rng: RandomSource, potatoBiasActive: boolean): EnemyRoll {
  if (potatoBiasActive && rng() < POTATO_DIRECT_RATE) return toRoll(potatoAi, true);
  const ai = AI_ENEMY_POOL[Math.floor(rng() * AI_ENEMY_POOL.length)];
  return toRoll(ai, potatoBiasActive);
}
```

非触发路径必须只消费一个随机数；触发且直达也只消费一个；触发 fallback 消费两个。不得偷偷过滤目标。
